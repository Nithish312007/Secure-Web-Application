# Secure Web Application using Flask

## Project Overview
This project is a Secure Web Application developed using Flask to demonstrate fundamental cybersecurity concepts such as authentication, password security, and secure data handling. The application allows users to register, login, and access a protected dashboard while following secure coding practices.

## Features
* User Registration System
* Secure Login Authentication
* Password Hashing using Bcrypt
* SQLite Database Integration
* Protected Dashboard Access
* Secure Data Storage Practices
* Basic Authentication Workflow

## Technologies Used
* Python
* Flask
* Flask-SQLAlchemy
* Flask-Bcrypt
* SQLite
* HTML


## Security Concepts Implemented
* Password hashing using Bcrypt
* Secure storage of credentials
* Authentication workflow
* Reduced SQL Injection risk using ORM
* Input handling through Flask forms

## Installation and Execution
1. Clone the repository
2. Create a virtual environment
3. Install dependencies
4. Run the application

## Output
The application provides:
* User Registration Page
* Login Authentication Page
* Dashboard after successful login
